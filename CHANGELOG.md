# What's New

## 1.0.0

- A rebuilt modern GTK4 interface with responsive navigation, device cards and GNOME accent-color support.
- Logitech USB cameras in the main sidebar with live numeric sliders and per-camera saved settings.
- Optional full-width 16:9 camera preview, off by default, with no audio, recording or uploading.
- Per-device saved settings with optional restoration after reconnecting or waking up.
- Named and application-specific profiles, manual override and validated backups/imports.
- Device-aware DPI limits and up to eight saved DPI presets.
- Custom keyboard shortcuts, tap/hold/double-tap actions and directional gestures on supported devices.
- Receiver management, pairing support and coordinated Easy-Switch host changes.
- Battery and charging status, configurable notifications and low-battery tray alerts.
- Light/dark themes, language selection and configurable login startup.
- Optional gaming, lighting, system-audio and Deskflow integrations.
- Device-aware JSON CLI and optional read-only GNOME foreground-application extension.
- Hardware-free protocol, persistence, input and GTK regression checks.
- Fedora 44 RPM installation, desktop integration and device-access rules.
- GitHub update notifications; updates are never installed automatically.
